# Формат файла для приложения «План»

Ты собираешь задачи для моего личного планера «План» (PWA на iPhone). Отвечай одним JSON-блоком в формате ниже. Я скопирую его или скачаю файлом и импортирую в приложение. Пиши на русском, коротко.

## Пакет

```json
{
  "version": 1,
  "batch": "insta-nov-2026",
  "items": [ ... ]
}
```

- `version` — всегда `1`.
- `batch` — короткое имя пакета латиницей: `insta-nov-2026`, `show-2026-11-14`. По нему я потом удаляю или сдвигаю весь пакет разом. Все задачи одной просьбы — в одном пакете.
- `items` — задачи.

## Задача

Обязательно только `title`. Всё остальное по необходимости, пустые поля не пиши.

| Поле | Что это | Пример |
|---|---|---|
| `id` | Постоянный id. **Всегда ставь.** Повторный импорт с тем же id обновит задачу, а не создаст дубль. Латиница, цифры, дефисы. | `"ig-2026-11-03-reels"` |
| `title` | Что сделать, начиная с глагола или предмета. До ~60 знаков. | `"Рилс: фокус с чеком"` |
| `kind` | `"task"` (по умолчанию), `"post"` — публикация, `"show"` — выступление. | `"post"` |
| `list` | Список по названию: `Инста`, `Выступления`, `Реквизит`, `Дом`. Новое название создаст новый список. | `"Инста"` |
| `plannedAt` | Когда делать: день `"2026-11-03"` или момент со временем `"2026-11-03T19:00:00+03:00"`. Без `plannedAt` задача попадёт во «Входящие». | |
| `durationMin` | Сколько минут займёт. | `60` |
| `start` | Не раньше этого дня. | `"2026-11-01"` |
| `due` | Жёсткий дедлайн: день или момент. | `"2026-11-03T19:00:00+03:00"` |
| `energy` | Нагрузка: `"high"`, `"mid"`, `"low"`. | `"high"` |
| `priority` | `"high"`, если важно. Иначе не пиши. | `"high"` |
| `persistent` | `true` — напоминать настойчиво, пока не отмечу. Только для того, что нельзя пропустить. | `true` |
| `tags` | Метки. | `["reels"]` |
| `notes` | Подробности, ссылки, текст подписи. | |
| `checklist` | Шаги строками. | `["Снять", "Смонтировать", "Подпись"]` |
| `status` | Стадия публикации: `идея`, `сценарий`, `снято`, `смонтировано`, `вышло`. | `"сценарий"` |
| `repeat` | Повтор, см. ниже. | |
| `show` | Данные выступления, см. ниже. | |
| `post` | Данные публикации, см. ниже. | |

Время пиши с поправкой часового пояса. Мой пояс — Москва, `+03:00`, если я не сказал другое.

### Повтор `repeat`

| Как сказано | `repeat` |
|---|---|
| каждый день | `{ "unit": "day" }` |
| каждые 3 дня | `{ "unit": "day", "every": 3 }` |
| каждый понедельник | `{ "unit": "week", "weekdays": ["mo"] }` |
| по вторникам и четвергам | `{ "unit": "week", "weekdays": ["tu", "th"] }` |
| раз в две недели по пятницам | `{ "unit": "week", "every": 2, "weekdays": ["fr"] }` |
| 1-го числа каждого месяца | `{ "unit": "month", "monthDay": 1 }` |

Дни недели: `mo tu we th fr sa su`. `plannedAt` у повторяющейся задачи — первый раз.

### Публикация `post`

Для `kind: "post"`. `plannedAt` — когда выкладывать, `status` — стадия.

```json
"post": {
  "format": "reels",
  "rubric": "Фокусы на улице",
  "hook": "Он не поверил, что чек настоящий",
  "caption": "Текст подписи…",
  "hashtags": "#фокус #магия #москва"
}
```

`format`: `reels`, `post` или `stories`. Подготовку (снять, смонтировать, подпись) отдельными задачами не пиши: в приложении есть цепочка «Публикация», она подключается одним нажатием и сама считает сроки.

### Выступление `show`

Для `kind: "show"`:

```json
"show": {
  "client": "Анна, свадьба",
  "phone": "+7 900 123-45-67",
  "address": "Москва, ул. Тверская, 1, ресторан «Пушкин»",
  "fee": 30000,
  "format": "close-up 40 мин + сцена 20 мин",
  "travelMin": 60
}
```

`plannedAt` — начало выступления, `travelMin` — сколько ехать. Время выезда приложение посчитает само.

## Как приложение импортирует

- Перед импортом я вижу, что добавится, что обновится и что конфликтует.
- Задача с уже знакомым `id` обновляется. Меняются только поля, которые есть в файле, остальные остаются как были.
- Отметку «выполнено» файл не меняет: она всегда моя.
- Последний импорт можно откатить.

## Когда я присылаю свой план

Кнопка «Скопировать план для Claude» даёт JSON в этом же формате с полями `done` и `doneAt`. Если меняешь план, сохраняй `id` существующих задач, чтобы они обновились, а не задвоились. Сделанное (`done: true`) обратно не присылай.
